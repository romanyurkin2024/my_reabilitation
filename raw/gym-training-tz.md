# ТЗ: тренировочная система с минимальной нагрузкой на поясницу

*Источник: разговор с ChatGPT, загружен 2026-08-10. Immutable.*

## 1. Цель

Сформировать программу тренировок в тренажёрном зале для пользователя с проблемной поясницей, где основной принцип:

«Максимально эффективно тренировать все основные группы мышц при минимальной осевой нагрузке и минимальном риске перегрузки поясницы.»

Программа должна учитывать не только отсутствие осевой нагрузки, но и то, что при создании усилия пользователь склонен автоматически переразгибать поясницу и перенапрягать её даже в упражнениях, которые напрямую не являются упражнениями на спину.

## 2. Ключевая особенность пользователя

При начале усилия пользователь замечает следующую реакцию:

напрягается → поясница автоматически начинает сильнее выгибаться → поясница перенапрягается.

Это происходит даже при упражнениях, которые не предназначены для тренировки спины.

Поэтому основным критерием выбора упражнения должна быть не только величина осевой нагрузки, но и возможность:

- стабильно зафиксировать корпус;
- контролировать положение таза;
- не уходить в гиперлордоз;
- не использовать поясницу как основной стабилизатор;
- выполнять движение без компенсации поясницей.

## 3. Общие принципы программы

При выборе упражнений использовать приоритет:

1. Тренажёры с фиксацией корпуса.
2. Упражнения с опорой груди/спины.
3. Упражнения сидя с хорошей опорой.
4. Лёжа.
5. Упражнения стоя — только если пользователь может выполнять их без переразгибания поясницы.

Избегать упражнений, где пользователь вынужден:
- удерживать большой вес корпусом;
- стабилизировать тяжёлый вес поясницей;
- сильно прогибаться;
- выполнять наклоны с весом;
- вращать позвоночник под нагрузкой.

## 4–16. Упражнения по группам мышц

### Грудь
- Жим в Hammer / тренажёре
- Жим гантелей лёжа
- Жим штанги лёжа (контроль поясницы)
- Сведение в тренажёре / кроссовере
- Отжимания
Приоритет: тренажёр → гантели → штанга.

### Широчайшие
- Тяга верхнего блока к груди
- Подтягивания / с резиной
- Тяга верхнего блока нейтральным хватом
- Одноручная тяга верхнего блока
- Пуловер в тренажёре / с канатом
- Тяга прямыми руками в кроссовере

### Средняя и верхняя часть спины
- Тяга горизонтального блока с опорой груди
- Тяга в Hammer с опорой груди
- Тяга гантелей лёжа грудью на наклонной скамье
- Тяга Т-грифа с упором грудью
- Reverse fly в тренажёре
- Face pull

### Задняя дельта
- Reverse pec deck
- Разведения гантелей лёжа грудью
- Face pull
- Одноручные разведения в кроссовере

### Средняя дельта
- Разведения гантелей сидя
- Разведения в тренажёре
- Разведения одной рукой в кроссовере
Предпочтение — сидя, не стоя.

### Передняя дельта
Не нужен отдельный объём — получает нагрузку в жимах.
- Подъём гантелей перед собой сидя (при необходимости)

### Бицепс
- Сгибание гантелей сидя
- Сгибание на скамье Скотта (особенно предпочтительно)
- Сгибание на наклонной скамье
- Сгибание в тренажёре
- Молотковые сгибания сидя

### Трицепс
- Разгибание на верхнем блоке / с канатом
- Разгибание в тренажёре
- Французский жим лёжа
- Жим узким хватом лёжа
- Отжимания на брусьях — только при отсутствии симптомов

### Квадрицепс
- Разгибание ног сидя в тренажёре (основной)
- Жим ногами (контроль амплитуды)
- Болгарские приседания — осторожно
- Step-up — осторожно
- Испанские приседания

### Задняя поверхность бедра
- Сгибание ног лёжа / сидя
- Сгибание одной ноги в тренажёре

### Ягодицы
- Ягодичный мост / Hip thrust
- Ягодичный мост на одной ноге
- Отведение ноги назад в кроссовере / тренажёре
- Разведение ног в тренажёре

### Икры
- Подъём на носки сидя (приоритет)

### Кор
Антиразгибание: McGill curl-up, Dead bug
Антивращение: Pallof press, Pallof hold
Антибоковое сгибание: боковая планка
Стабилизация: Bird dog, Bear plank

НЕ использовать: классические скручивания, sit-up, русские скручивания, вращения с весом.

## 17. Исключить полностью

- Тяжёлые приседания со штангой
- Становая тяга
- Румынская тяга тяжёлая
- Good morning
- Тяжёлые наклоны со штангой
- Тяжёлая тяга штанги в наклоне без опоры
- Тяжёлый армейский жим стоя
- Тяжёлые шраги стоя
- Farmer's walk тяжёлый
- Скручивания с весом
- Резкие вращения корпуса

## 18. Ключевое правило выполнения

«Если во время подхода поясница начинает забирать движение — подход остановить, даже если целевая мышца ещё способна выполнить несколько повторений.»

## 19. Разминка перед силовой тренировкой

1. 90/90 breathing — 4–5 дыхательных циклов
2. Dead bug — 2×6–8 на сторону
3. Bird dog — 2×6 на сторону
4. Ягодичный мост — 2×8–10
5. Первое упражнение с 50–60% рабочего веса

## 20. Тест каждого упражнения

A. Контроль поясницы — нейтральное положение сохраняется?
B. Фиксация корпуса — есть опора?
C. Компенсации — появляется выгибание при увеличении веса?
D. Симптомы — боль, стрельба, онемение, слабость?

## 21. Предварительная структура (4 дня)

### Верх А
1. Жим в Hammer — 3×8–12
2. Тяга верхнего блока — 3×8–12
3. Тяга горизонтального блока с опорой груди — 3×8–12
4. Разведения на среднюю дельту сидя — 3×12–15
5. Сгибание на Скотте — 3×10–15
6. Разгибание рук на блоке — 3×10–15
7. Pallof press — 3×10–15

### Низ А
1. Разгибание ног — 3×10–15
2. Сгибание ног сидя — 3×10–15
3. Hip thrust в тренажёре — 3×8–12
4. Разведение ног — 3×12–20
5. Икры сидя — 3×12–20
6. Dead bug — 3 подхода
7. Bird dog — 3 подхода

### Верх B / Низ B — аналогичная логика без дублирования нагрузки.

## 22. Главный критерий успеха

«Научиться создавать высокое мышечное усилие без автоматического переразгибания и перенапряжения поясницы.»

Прогрессия: техника → контроль корпуса → повторения → вес.
